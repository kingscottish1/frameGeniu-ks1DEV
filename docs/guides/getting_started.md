# Getting started

1. Install with `INSTALL.bat` or `scripts/setup_env.sh`.
2. Start with `START.bat` or `python scripts/launch.py --all`.
3. Open http://127.0.0.1:8501
4. Generate → type a topic → Render video.
5. Wait for the preview. Download the MP4 from Library.

First render uses demo writing + local stills + Edge TTS. That is intentional.
When you are ready, drop a Pexels key and switch the LLM provider in Settings.
