# Custom templates

1. Copy `resource/templates/motivational.json` to `resource/templates/mylook.json`.
2. Drop a cover still at `resource/templates/covers/mylook.jpg`.
3. Add a writer function in `app/services/script.py` and register it in `TEMPLATES`.
4. Select it in the Generate page.

Keep narration short. Search terms must be **visual nouns** (`aerial pine forest`) not abstractions (`success mindset`).
